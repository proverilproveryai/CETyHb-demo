CETyHb is a long-form generative series inspired by Setun, the Soviet balanced-ternary computer built at Moscow State University in 1958. Each token is a terminal running a program in TRIT, a fictional ternary language, on a triangular grid. Open the code, edit it and press RUN; press "?" on interface for syntax list and another info.

Fully on-chain: the artwork code, its interpreter and every token's hash are stored in the Ethereum contract itself, with no servers and no IPFS. This page only reads the contract; every token is available on OpenSea and directly on Etherscan.
